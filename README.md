# LiftVision Control

Plataforma web de monitoramento e inspeção inteligente para operações de içamento de cargas, utilizando conceitos de visão computacional, sensores, drone de apoio e validação automática de segurança.

## Sobre o Projeto

O **LiftVision Control** foi desenvolvido com o objetivo de auxiliar operações industriais envolvendo guindastes e movimentação de cargas, tornando o processo mais seguro, organizado e monitorável.

A plataforma permite acompanhar etapas importantes antes do içamento, como a inspeção visual da carga, verificação das cintas, validação dos itens críticos de segurança e organização dos registros por container, horário e local.

O sistema foi pensado para reduzir riscos operacionais, evitar falhas durante o içamento e fornecer maior controle para equipes responsáveis por segurança industrial.

## Objetivo da Plataforma

O principal objetivo do LiftVision Control é acompanhar o processo de inspeção de cargas antes do içamento, verificando:

- Condição das cintas;
- Fechamento das manilhas;
- Integridade dos pontos de fixação;
- Registro visual da operação;
- Organização das fotos por pasta técnica;
- Validação dos itens críticos de segurança.

## Estrutura do Sistema

O site possui uma interface lateral com navegação entre as principais áreas da plataforma:

- **Início:** apresentação da solução e objetivo da plataforma;
- **Dashboard:** área para visualização de dados e acompanhamento;
- **Produtos:** seção destinada aos recursos ou módulos do sistema;
- **Containers:** controle e organização das cargas;
- **Fotos:** catálogo visual com registros da inspeção.

## Resumo da Solução

O LiftVision Control simula uma plataforma industrial capaz de receber imagens de inspeção e dados operacionais, processar essas informações e auxiliar na tomada de decisão antes da liberação do içamento.

A proposta é trazer mais segurança para operações com cargas pesadas, utilizando tecnologia como suporte para inspeções, validações e rastreabilidade.
